INTEGRATION GUIDE / MP-IG-01 / r1

From product choice
to engineering handoff.

A requirements checklist for scoping a project. This guide does not replace a released product manual or operating procedure.

01 / TECHNICAL HANDOFF

Define the task

  • Application, operating environment and expected duty cycle
  • Required motion, working space and allowable envelope
  • Target loads and the difference between continuous and transient demands
02 / TECHNICAL HANDOFF

Freeze the mechanical interface

  • Drawing revision, coordinate frames and mounting datums
  • Fastener specification, tolerances and cable routing
  • External loads, travel limits and clearance through the full motion range
03 / TECHNICAL HANDOFF

Agree power and communication

  • Voltage range, current limits and supply behavior
  • Connector part number, pinout, grounding and termination
  • Protocol and firmware versions, control timing and error handling
04 / TECHNICAL HANDOFF

Request the software package

  • API documentation, SDK example and compatible firmware
  • Simulation model and the assumptions it contains
  • Distribution rights, applicable license and update process
05 / TECHNICAL HANDOFF

Define acceptance

  • Measurement method, instruments and operating conditions
  • Thermal limits, duty cycle and configuration-specific performance
  • Revision traceability, build record and agreed deliverables

Build a package request.

Select a model and choose the documents you need. The next step prepares an inquiry; it does not submit one.
