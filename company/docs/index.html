How to read the evidence labels

Reported: transcribed from a supplied source, with no independent test claim. Target: a development or design goal. Pending: a value or release detail has not been established. Conflict: the source contains incompatible statements.

Earlier promotional figures are not merged into the selected model snapshots. A technical agreement should cite the hardware revision and acceptance conditions.
